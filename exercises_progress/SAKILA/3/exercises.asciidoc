= Exercises
:toc: left
:toclevels: 3

The exercises on the installed `sakila` database: a section for each table and view, with a section for each level, and, at the end, a section for the schema as a whole.
Each exercise poses a problem; its answer, and what the installed data gives back, are in the `.sql` file, and are checked by an integration test.

Run a file as a whole:

[source,sh]
----
docker exec -i mysql-sakila mysql -uroot -p'Passw0rd!' -t sakila < src/test/sql-exercises/<section>/<NN>_<level>.sql
----

[[SAKILA_ADDRESS_I_01]]
==== SAKILA_ADDRESS_I_01: the first five addresses, with their city and country

Show the first five addresses by `address_id`, each with the name of its city and the name of that city's country.
An address refers to a city (`city_id`), and a city to a country (`country_id`), so the query joins three tables in a chain.

.`address/02_intermediate.sql`, SAKILA_ADDRESS_I_01
[%collapsible]
====
[source,sql]
----
SELECT a.address_id, a.address, a.address2, a.district, a.city_id, a.postal_code, a.phone, a.last_update, ci.*, co.* -- every column but location, a GEOMETRY which does not print
FROM address a
         JOIN city ci ON ci.city_id = a.city_id
         JOIN country co ON co.country_id = ci.country_id
ORDER BY a.address_id
LIMIT 5
----

[[SAKILA_ADDRESS_I_02]]
==== SAKILA_ADDRESS_I_02: the district names found in more than one country

The same district name may appear in different countries.
Group the addresses by `district`, join `city` to reach the country, and keep the districts whose addresses lie in more than one country; leave out the empty district.
Show each district with its number of countries, the most first; districts with the same number are ordered by name.

.`address/02_intermediate.sql`, SAKILA_ADDRESS_I_02
[%collapsible]
====
[source,sql]
----
SELECT a.district, COUNT(DISTINCT ci.country_id) AS countries
FROM address a
         JOIN city ci ON ci.city_id = a.city_id
WHERE a.district <> ''
GROUP BY a.district
HAVING COUNT(DISTINCT ci.country_id) > 1
ORDER BY countries DESC, a.district
----

[[SAKILA_ADDRESS_I_03]]
==== SAKILA_ADDRESS_I_03: how many addresses belong to a store, a staff member or a customer

Classify each address by who refers to it: a store, else a staff member, else a customer, else nobody.
Show each class with its number of addresses, the most first; classes with the same number are ordered by name.
A `CASE` of `EXISTS` conditions gives the class, and the first condition that holds wins.

.`address/02_intermediate.sql`, SAKILA_ADDRESS_I_03
[%collapsible]
====
[source,sql]
----
SELECT CASE
           WHEN EXISTS (SELECT 1 FROM store s WHERE s.address_id = a.address_id) THEN 'store'
           WHEN EXISTS (SELECT 1 FROM staff s WHERE s.address_id = a.address_id) THEN 'staff'
           WHEN EXISTS (SELECT 1 FROM customer c WHERE c.address_id = a.address_id) THEN 'customer'
           ELSE 'none'
           END  AS used_by,
       COUNT(*) AS addresses
FROM address a
GROUP BY used_by
ORDER BY addresses DESC, used_by
----

====

[[SAKILA_ADDRESS_A_02]]
==== SAKILA_ADDRESS_A_02: the pairs of addresses which share a postal code

Find the pairs of different addresses with the same `postal_code`, leaving out the empty postal code.
Show each pair once: the `address_id` and the `address` of both, and the postal code, ordered by the first `address_id` and then by the second.
A self join of `address`; the condition that the second id is larger than the first keeps each pair once and drops an address paired with itself.

.`address/03_advanced.sql`, SAKILA_ADDRESS_A_02
[%collapsible]
====
[source,sql]
----
SELECT a1.address_id, a1.address, a1.address2, a1.district, a1.city_id, a1.postal_code, a1.phone, a1.last_update, -- every column but location, a GEOMETRY which does not print
       a2.address_id, a2.address, a2.address2, a2.district, a2.city_id, a2.postal_code, a2.phone, a2.last_update
FROM address a1
         JOIN address a2 ON a2.postal_code = a1.postal_code AND a2.address_id > a1.address_id
WHERE a1.postal_code <> ''
ORDER BY a1.address_id, a2.address_id
----

[[SAKILA_ADDRESS_A_03]]
==== SAKILA_ADDRESS_A_03: the three districts with the most addresses in each of India, China and the United States

Count the addresses of each district in India, in China and in the United States, and keep the three districts with the most addresses in each country.
Show the country, the district and the count, ordered by the country and then by the count, the most first; districts with the same count are ordered by name.
A top-N per group: `ROW_NUMBER()` over a partition by country numbers the districts, and the outer query keeps the first three.

.`address/03_advanced.sql`, SAKILA_ADDRESS_A_03
[%collapsible]
====
[source,sql]
----
SELECT country, district, addresses
FROM (SELECT co.country,
             a.district,
             COUNT(*)                                                                       AS addresses,
             ROW_NUMBER() OVER (PARTITION BY co.country_id ORDER BY COUNT(*) DESC, a.district) AS district_rank
      FROM address a
               JOIN city ci ON ci.city_id = a.city_id
               JOIN country co ON co.country_id = ci.country_id
      WHERE co.country IN ('India', 'China', 'United States')
      GROUP BY co.country_id, co.country, a.district) ranked
WHERE district_rank <= 3
ORDER BY country, district_rank
----

[[SAKILA_COUNTRY_A_01]]
==== SAKILA_COUNTRY_A_01: the fewest countries which hold half of the customers

Count the customers of each country, and order the countries by the count, the most first, ties by the name.
Keep a running total of the counts (`SUM() OVER (ORDER BY ...)`) and stop at the first country with which the total reaches half of all the customers.
Show each country, its count, the running total and the running total as a percentage of all the customers, rounded to two decimal places.

.`country/03_advanced.sql`, SAKILA_COUNTRY_A_01
[%collapsible]
====
[source,sql]
----
WITH counted AS (SELECT co.country, COUNT(*) AS customers
                 FROM country co
                          JOIN city ci ON ci.country_id = co.country_id
                          JOIN address a ON a.city_id = ci.city_id
                          JOIN customer cu ON cu.address_id = a.address_id
                 GROUP BY co.country_id, co.country),
     running AS (SELECT counted.*,
                        SUM(customers) OVER (ORDER BY customers DESC, country) AS running_total,
                        SUM(customers) OVER () AS total
                 FROM counted)
SELECT country, customers, running_total, ROUND(100 * running_total / total, 2) AS running_percent
FROM running
WHERE running_total - customers < total / 2
ORDER BY customers DESC, country
----

====


[[SAKILA_COUNTRY_A_02]]
==== SAKILA_COUNTRY_A_02: the countries ranked in the top ten by customers, ties sharing a rank

Rank the countries by their number of customers with `RANK()`, so that countries with the same count share a rank and the next rank is skipped.
Show the countries whose rank is ten or better, with their counts and ranks, ordered by the rank; ties are ordered by the name.
Unlike `LIMIT 10`, the cut keeps every country tied at the edge.

.`country/03_advanced.sql`, SAKILA_COUNTRY_A_02
[%collapsible]
====
[source,sql]
----
SELECT country, customers, ranking
FROM (SELECT co.country, COUNT(*) AS customers, RANK() OVER (ORDER BY COUNT(*) DESC) AS ranking
      FROM country co
               JOIN city ci ON ci.country_id = co.country_id
               JOIN address a ON a.city_id = ci.city_id
               JOIN customer cu ON cu.address_id = a.address_id
      GROUP BY co.country_id, co.country) t
WHERE ranking <= 10
ORDER BY ranking, country
----

====
