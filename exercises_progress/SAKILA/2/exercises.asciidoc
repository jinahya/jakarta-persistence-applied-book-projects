= Exercises
:toc: left
:toclevels: 3

The exercises on the installed `sakila` database: a section for each table and view, with a section for each level, and, at the end, a section for the schema as a whole.
Each exercise poses a problem; its answer, and what the installed data gives back, are in the `.sql` file, and are checked by an integration test.

Run a file as a whole:

[source,sh]
----
docker exec -i mysql-sakila mysql -uroot -p'Passw0rd!' -t sakila < src/test/sql-exercises/<section>/<NN>_<level>.sql
----

[[SAKILA_CATEGORY_I_02]]
==== SAKILA_CATEGORY_I_02: the category whose films are, on average, the longest

For each category, take the average `length` of its films, and find the category whose average is the largest.
Show its name and the average, rounded to two decimal places.
Order the groups by the average and keep only the first.

.`category/02_intermediate.sql`, SAKILA_CATEGORY_I_02
[%collapsible]
====
[source,sql]
----
SELECT c.*, ROUND(AVG(f.length), 2) AS average_length
FROM category c
         JOIN film_category fc ON fc.category_id = c.category_id

GROUP BY c.category_id
ORDER BY average_length DESC
LIMIT 1
----

[[SAKILA_CATEGORY_I_04]]
==== SAKILA_CATEGORY_I_04: the categories whose films rent for more than the average

For each category, take the average `rental_rate` of its films, and keep the categories whose average is higher than the average over all films.
Show each such category's name and its average rounded to two decimal places, the highest first; categories with the same rounded average are ordered by name.
The overall average comes from a subquery in `HAVING`.

.`category/02_intermediate.sql`, SAKILA_CATEGORY_I_04
[%collapsible]
====
[source,sql]
----
SELECT c.*, ROUND(AVG(f.rental_rate), 2) AS average_rental_rate
FROM category c
         JOIN film_category fc ON fc.category_id = c.category_id
         JOIN film f ON f.film_id = fc.film_id
GROUP BY c.category_id
HAVING AVG(f.rental_rate) > (SELECT AVG(rental_rate) FROM film)
ORDER BY average_rental_rate DESC, c.name
----

[[SAKILA_CATEGORY_A_01]]
==== SAKILA_CATEGORY_A_01: the running total of the films, category by category

Count the films of each category, and, going from the category with the most films down, add up the counts as a running total and as a running percentage of all films.
Show each category's name, its number of films, the running total and the running percentage rounded to one decimal place; categories with the same count are ordered by name.
Window functions over the grouped rows: `SUM(COUNT(*)) OVER (ORDER BY ...)` for the running total and `SUM(COUNT(*)) OVER ()` for the whole.

.`category/03_advanced.sql`, SAKILA_CATEGORY_A_01
[%collapsible]
====
[source,sql]
----
SELECT c.*,
       COUNT(*)                                                         AS films,
       SUM(COUNT(*)) OVER (ORDER BY COUNT(*) DESC, c.name)              AS running_films,
       ROUND(100 * SUM(COUNT(*)) OVER (ORDER BY COUNT(*) DESC, c.name)
                 / SUM(COUNT(*)) OVER (), 1)                            AS running_percent
FROM category c
         JOIN film_category fc ON fc.category_id = c.category_id
GROUP BY c.category_id
ORDER BY films DESC, c.name
----

====


[[SAKILA_CATEGORY_A_02]]
==== SAKILA_CATEGORY_A_02: the film rented the most in each category

Count the rentals of each film, through `inventory` and `rental`, and find, in each category, the film with the most rentals.
Show the category's name, the film's `title` and its number of rentals, ordered by the category's name; when films of a category tie, the one whose title comes first is shown.
A top-1 per group: `ROW_NUMBER()` over a partition by category.

.`category/03_advanced.sql`, SAKILA_CATEGORY_A_02
[%collapsible]
====
[source,sql]
----
SELECT name, title, rentals
FROM (SELECT c.name,
             f.title,
             COUNT(*)                                                                    AS rentals,
             ROW_NUMBER() OVER (PARTITION BY c.category_id ORDER BY COUNT(*) DESC, f.title) AS film_rank
      FROM category c
               JOIN film_category fc ON fc.category_id = c.category_id
               JOIN film f ON f.film_id = fc.film_id
               JOIN inventory i ON i.film_id = f.film_id
               JOIN rental r ON r.inventory_id = i.inventory_id
      GROUP BY c.category_id, c.name, f.film_id, f.title) ranked
WHERE film_rank = 1
ORDER BY name
----

====

[[SAKILA_FILM_CATEGORY_A_01]]
==== SAKILA_FILM_CATEGORY_A_01: the longest film of each category

For each category, find its longest film.
Show the category's name, the film's `film_id`, `title` and `length`, ordered by the category's name.
Several films of a category may share the longest length; take the one with the smallest `film_id`.
Number the films of each category with `ROW_NUMBER()`, partitioned by the category, and keep the first.

.`film_category/03_advanced.sql`, SAKILA_FILM_CATEGORY_A_01
[%collapsible]
====
[source,sql]
----
SELECT name, film_id, title, length
FROM (SELECT c.name, f.film_id, f.title, f.length,
             ROW_NUMBER() OVER (PARTITION BY c.category_id ORDER BY f.length DESC, f.film_id) AS rn
      FROM film_category fc
               JOIN category c ON c.category_id = fc.category_id
               JOIN film f ON f.film_id = fc.film_id) t
WHERE rn = 1
ORDER BY name
----

====


[[SAKILA_FILM_CATEGORY_A_02]]
==== SAKILA_FILM_CATEGORY_A_02: the pairs of categories which have the same number of films

Find the pairs of categories which have the same number of films.
Join `category` with itself, keeping each pair once, the name which comes first on the left, and compare the two counts, each a correlated subquery on `film_category`.
Show the two names and the number of films, the largest number first; ties are ordered by the two names.

.`film_category/03_advanced.sql`, SAKILA_FILM_CATEGORY_A_02
[%collapsible]
====
[source,sql]
----
SELECT c1.*, c2.*,
       (SELECT COUNT(*) FROM film_category fc WHERE fc.category_id = c1.category_id) AS films
FROM category c1
         JOIN category c2 ON c1.name < c2.name
WHERE (SELECT COUNT(*) FROM film_category fc WHERE fc.category_id = c1.category_id)
          = (SELECT COUNT(*) FROM film_category fc WHERE fc.category_id = c2.category_id)
ORDER BY films DESC, c1.name, c2.name
----

[[SAKILA_INVENTORY_A_01]]
==== SAKILA_INVENTORY_A_01: the five longest times a copy sat on the shelf between two rentals

For each rental of a copy, find the copy's next rental, and the days between the return and that next rental.
Leave out the rentals of 2006, which all fall on one day, months after the others.
Show the five longest: the `inventory_id`, the `return_date`, the next rental's date and the days, the most days first; ties are ordered by `inventory_id` and then by `return_date`.
Find the next rental with `LEAD()`, partitioned by the copy and ordered by the rental date and the rental's id.

.`inventory/03_advanced.sql`, SAKILA_INVENTORY_A_01
[%collapsible]
====
[source,sql]
----
WITH rentals AS (SELECT r.inventory_id, r.rental_date, r.return_date,
                        LEAD(r.rental_date) OVER (PARTITION BY r.inventory_id ORDER BY r.rental_date, r.rental_id) AS next_rental_date
                 FROM rental r
                 WHERE r.rental_date < '2006-01-01')
SELECT inventory_id, return_date, next_rental_date,
       DATEDIFF(next_rental_date, return_date) AS idle_days
FROM rentals
WHERE return_date IS NOT NULL
  AND next_rental_date IS NOT NULL
ORDER BY idle_days DESC, inventory_id, return_date
LIMIT 5
----

[[SAKILA_SALES_BY_FILM_CATEGORY_A_02]]

Order the categories by `total_sales`, the most first; on a tie, by `category`.

[source,sql]

SELECT category, total_sales, next_category, total_sales - next_sales AS gap
FROM (SELECT category, total_sales,
             LEAD(category) OVER (ORDER BY total_sales DESC, category) AS next_category,
             LEAD(total_sales) OVER (ORDER BY total_sales DESC, category) AS next_sales
      FROM sales_by_film_category) g
WHERE next_category IS NOT NULL
ORDER BY gap DESC, category
LIMIT 3

[[SAKILA_SALES_BY_FILM_CATEGORY_A_03]]
==== SAKILA_SALES_BY_FILM_CATEGORY_A_03: each category's rank by sales, next to its rank by rentals

A category may sell much because its films rent for more, not because they are rented more.
Count the rentals of each category, through the copy and `film_category`, and join the counts to the view by the category's name.
Rank the categories twice with `RANK()`, by `total_sales` and by the rentals, and show each category's `total_sales`, its rank, its rentals and that rank, ordered by the sales rank; on a tie, by `category`.

.`sales_by_film_category/03_advanced.sql`, SAKILA_SALES_BY_FILM_CATEGORY_A_03
[%collapsible]
====
[source,sql]
----
WITH rented AS (SELECT c.name AS category, COUNT(*) AS rentals
                FROM rental r
                         JOIN inventory i ON i.inventory_id = r.inventory_id
                         JOIN film_category fc ON fc.film_id = i.film_id
                         JOIN category c ON c.category_id = fc.category_id
                GROUP BY c.name)
SELECT s.*,
       RANK() OVER (ORDER BY s.total_sales DESC) AS sales_rank,
       rd.rentals,
       RANK() OVER (ORDER BY rd.rentals DESC)    AS rentals_rank
FROM sales_by_film_category s
         JOIN rented rd ON rd.category = s.category
ORDER BY sales_rank, s.category
----
